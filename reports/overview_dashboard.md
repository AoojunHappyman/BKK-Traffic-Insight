พื้นหลัง `#111512`, surface `#191e1a`, สีเน้น `#d7f78b`, Arial และหัวข้อย่อย Consolas
ใช้เมนูด้านบน ปุ่ม/เส้นขอบบาง และโหมดสว่าง/มืดที่จำตัวเลือกในเบราว์เซอร์
กราฟเปลี่ยนสีแกน แท่ง และ tooltip ตามธีม ตัวกรองและข้อมูลเดิมยังใช้ API เดิม

เปิดหน้า `/` ที่ Flask server เพื่อดูข้อมูลจริงจาก MySQL

- กรองวันที่แบบรวมวันแรก/วันสุดท้าย และสถานที่ตามชื่อในรายงาน
- การ์ดจำนวนรถ กลุ่มสำรวจ กลุ่มถนน และจำนวนรายการช่วงเวลา
- Chart.js แสดงยอดรวมแยกตามช่วงเวลา พร้อมจำนวนรายการและระยะเวลาใน tooltip
- ตารางสูงสุด 10 ชื่อสถานที่ตามยอดรวม พร้อมจำนวนกลุ่มสำรวจและวันแรก/ล่าสุด
- แสดงขอบเขตข้อมูล 9 กลุ่มที่แยกไว้ตรวจต่อและ 32 กลุ่มที่ผ่านแต่ไม่มีพิกัด
  ตัวเลขความครอบคลุมนี้เป็นทั้งชุดข้อมูล ไม่เปลี่ยนตามตัวกรอง
- มีสถานะกำลังโหลด ไม่พบข้อมูล และเชื่อมต่อไม่ได้; ไม่แสดงผลเดิมเป็นผลของตัวกรองใหม่

API: `/api/overview` ใช้ตัวกรองเดียวกับ traffic API; `/api/overview/options`
ให้ช่วงวันที่ รายชื่อสถานที่และขอบเขตทั้งชุด ข้อมูลมาจาก MySQL ไม่ใช่ mock data
JS ใช้ textContent แสดงชื่อจากข้อมูล ยกเลิก request เดิมเมื่อเปลี่ยนตัวกรอง
กราฟมีข้อความตัวเลขประกอบเพื่อให้เข้าถึงข้อมูลได้แม้ canvas ไม่พร้อม
Chart.js 4.5.1 และ MIT license เก็บใน static/vendor เพื่อใช้งานในเครื่อง
