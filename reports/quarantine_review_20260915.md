## เหตุผลที่ยังไม่ปลดกัก

ไฟล์รายงานฝังเพียง **saved external values** ของ 4 workbook ที่อ้างถึง (18, 18, 36 และ 54 เซลล์)
ไม่มีข้อมูลรายย่อยหรือสูตรต้นทางครบให้คำนวณยืนยันอย่างอิสระ ไม่พบ workbook ทั้ง 4 ในชุด `Report` ที่ได้รับ
ค่าค้างในเซลล์รายงานกับค่าค้างของ external link อาจมาจาก snapshot เดียวกัน การตรงกันจึงไม่ยืนยัน upstream
ตรวจเทียบแล้วทั้ง 126 เซลล์มีค่าค้างสองตำแหน่งตรงกันจริง แต่ไม่ถือเป็นหลักฐานอิสระ

สองกลุ่มที่มีถนนพร้อมข้อมูลข้างชุดแถวว่างมีโอกาสเป็นแบบฟอร์มเหลือใช้ แต่ยังแยกจากข้อมูลตกหล่นไม่ได้
ตัวอย่างปากซอยพุทธบูชา 42 แสดงชัดว่า SUM ของช่องว่างให้ 0 ได้ทั้งที่ไม่มีจำนวนรถให้ใช้
การลบชุดแถวว่างจะเปลี่ยนสมมติฐานเรื่องความครบถ้วนของกลุ่ม จึงยังไม่ทำโดยไม่มีหลักฐานเพิ่ม
ข้อมูลถนนที่อ่านได้ในกลุ่มเหล่านี้เก็บอยู่ในหลักฐาน ไม่ถูกนำไปสร้างยอดสำรวจที่ดูเหมือนครบแล้ว

## ตรวจซ้ำและนำกลับเมื่อได้หลักฐาน

```powershell
.\.venv\Scripts\python.exe -m pipeline.audit_quarantine 'C:\Users\ASUS\Downloads\Report' --baseline data/processed/run_without_2022 --output reports/quarantine_audit_NEW_RUN
.\.venv\Scripts\python.exe -m pipeline.clean 'C:\Users\ASUS\Downloads\Report' --output data/processed/run_NEW_RUN
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

คำสั่ง audit อ่านอย่างเดียวและไม่ปลดกักอัตโนมัติ ใช้ output ใหม่ทุกครั้งเพื่อเก็บประวัติ
เมื่อได้หลักฐานใหม่ ให้บันทึกค่าก่อน/หลัง ไฟล์/ชีต/เซลล์ที่ยืนยัน SHA-256 และเหตุผลรายรายการ
จากนั้นใช้ correction ที่จำกัดเฉพาะรายการนั้น ตรวจ category → interval → road → survey totals และตรวจซ้ำทั้งชุดก่อน import
หากแก้ไฟล์ XLSX จน hash เปลี่ยน ต้องทำ migration ของ source revision อย่างชัดเจน เพราะ importer เดิมตั้งใจปฏิเสธ revision ที่ต่างจากไฟล์ซึ่งโหลดแล้ว
ไม่ใช้การนำไฟล์ revision ใหม่เข้าเพิ่มเพื่อหลบข้อกำหนดนี้ เพราะจะเสี่ยงนับข้อมูลซ้ำ
