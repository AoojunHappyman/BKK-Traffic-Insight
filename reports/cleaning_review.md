ผลตรวจซ้ำ 15 กันยายน 2026: [ตรวจ 9 กลุ่มกับ Excel ต้นฉบับ](quarantine_review_20260915.md)
ตรวจครบแล้ว ยังไม่มีค่าทดแทนที่พิสูจน์ได้ จึงคงกักไว้ทั้ง 9 กลุ่ม พร้อมหลักฐานรายเซลล์และรายการเอกสารที่ต้องใช้ยืนยัน

อัปเดต: นำปี 2022 ออกจากชุดใช้งานแล้ว ชุดปัจจุบันคือ `data/processed/run_without_2022/`
มี 820 กลุ่มสำรวจ / 4,707 แถว ข้อมูลด้านล่างเก็บผลตรวจครั้งแรกเป็นประวัติ

ตรวจเมื่อ 9 กันยายน 2026 (เวลาไทย) จาก XLSX 31 ไฟล์ใน `Downloads/Report`

โฟลเดอร์ `_01`, `_02`, `_03` เป็นผลทดลองระหว่างปรับ parser

## พิกัดและช่วงเวลา

พิกัดผิดรูปแบบ/นอกช่วงที่เป็นไปได้ 13 กลุ่ม; ไม่มี/กำกวม 21 กลุ่ม
ในชุดที่ผ่านมี 32 กลุ่มที่ไม่มีพิกัดใช้งานได้ ต้องเว้นจากแผนที่พร้อมแจ้งความครอบคลุม
แต่ยังใช้จำนวนรถวิเคราะห์ตามวัน/ช่วงเวลาได้
ตัวอย่าง `Apr2025.xlsx!N134` คือ `13.678893  10.0.609137` จึงเก็บ raw และปล่อยพิกัดว่าง
พบสูตรนอกตารางที่ `Apr2025.xlsx!X119` จึงบันทึก warning และไม่ใช้เป็น traffic fact
ไม่พบ duplicate candidates ในชุดสุดท้ายตามคีย์ที่กำหนด

| ช่วงเวลาที่ผ่าน | จำนวนแถว |
|---|---:|
| 07:00–09:00 | 1,617 |
| 09:00–17:00 | 1,569 |
| 17:00–19:00 | 1,569 |
| 09:00–16:00 | 48 |
| 16:00–19:00 | 48 |

ช่วงเวลามีระยะเวลาไม่เท่ากัน หากคำนวณ vehicles/hour ต้องระบุว่าเป็นอัตราเฉลี่ย
ตลอดช่วงสำรวจ ไม่ใช่ยอดรายชั่วโมงที่วัดได้จริง และยังสรุป peak hour จริงไม่ได้
เดือนรายงานไม่ได้แปลว่ามีการสำรวจครบทุกวันหรือครบทุกทางแยกในกรุงเทพฯ

## การทดสอบและขอบเขต

- Unit tests 13 รายการผ่าน: วันที่ พ.ศ./ปีอธิกสุรทิน รูปแบบชื่อ/วันที่
  ศูนย์/ค่าว่าง/เศษ/ค่าติดลบ สูตรภายนอก ยอดผิด วงจรสูตร ช่วงเวลาซ้อน
  duplicates และการแยกทั้งกลุ่มพร้อมตรวจต้นฉบับไม่เปลี่ยน
- รัน schema และโหลดข้อมูลที่ผ่านลง MySQL 9.7.1 ชั่วคราวครบ 5 ตาราง
  ตรวจจำนวนแถวและยอด `vehicle_total` ที่ MySQL คำนวณตรงกับ Python
- MySQL ปฏิเสธ duration ผิด ค่าติดลบ FK ถนนที่ไม่มี พิกัดผิด และเดือนรายงานไม่ตรง
  วันสำรวจตามคาด ปิด server ชั่วคราวหลังตรวจแล้ว
- ยังไม่ได้เชื่อม Flask กับ MySQL ที่ใช้งานจริง และยังไม่สร้าง Dashboard

ขั้นถัดไป: importer แบบ transaction และการเชื่อม MySQL ผ่าน environment variables
แล้วเพิ่ม API จากข้อมูลที่ผ่าน พร้อมแสดงข้อจำกัดและจำนวนกลุ่มที่ถูกกันไว้
