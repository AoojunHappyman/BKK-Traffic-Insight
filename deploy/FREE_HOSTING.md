# Free portfolio hosting: Render + Aiven

This alternative keeps Flask, Docker, MySQL, the reviewed dataset, and shared
Redis rate limits. It does not require a VPS or a purchased domain.

- Render Free web service: Docker/Gunicorn and an HTTPS `onrender.com` URL.
- Render Free Key Value: Redis-compatible rate-limit counters, private access.
- Aiven Free MySQL: persistent survey data, accessed over verified TLS.

`render.yaml` creates only explicitly free Render services. It uses one worker,
two threads, and a 10,000-row export ceiling to fit the small web instance.
Use the existing VPS Compose file only for a separate, paid VPS deployment.

## Account setup and MySQL

Sign into Render and Aiven yourself. Select **Free**, not an expiring paid trial.
Aiven's service password is generated by the provider. Download its CA certificate
and keep credentials in a local ignored `.env.aiven` file for the import:

```dotenv
DB_HOST=<Aiven host>
DB_PORT=<Aiven port>
DB_NAME=bangkok_traffic
DB_USER=<Aiven administrative user for first import>
DB_PASSWORD=<Aiven password>
DB_SSL_CA=C:/absolute/path/to/ca.pem
```

Never add credentials or the real dataset to Git. Keep the local development
`.env` unchanged. The following command loads `.env.aiven` only into the import
process, creates the schema in an empty target, and imports the reviewed bundle:

```powershell
.\.venv\Scripts\python.exe -c "from dotenv import load_dotenv; load_dotenv('.env.aiven', override=True); from pipeline.import_mysql import main; main(['data/processed/run_without_2022', '--init-schema'])"
```

Check the host before running this command. The database must be the new Aiven
service. On subsequent imports omit `--init-schema`; the importer rejects changed
rows and treats identical rows as unchanged. Verify the reported observation
count and total against the cleaning summary before publishing the web service.

Create a separate database user for the web service and grant it SELECT on
`bangkok_traffic.*`. Use that user's credentials in Render; retain the import
account separately. Restrict database access to Render's outbound IP ranges plus
the current import machine as the provider's controls allow.

## Render Blueprint

Connect the repository and create a Blueprint using `render.yaml`. Supply the
Aiven host, port, read-only user, and password at the secret prompts. For
`DB_SSL_CA_PEM`, paste the complete CA certificate including the BEGIN/END lines
as a multiline value. This is the CA certificate, never a private key.

The application checks both the CA chain and database hostname. Missing or bad
certificate material must be corrected rather than disabling verification.

The Blueprint links the web service to its private Key Value connection string.
If the workspace already has a free Key Value instance, inspect its region and
capacity and connect to it with a separate rate-limit namespace; do not replace
an existing service. Render allows only one free Key Value instance per workspace.

Render terminates HTTPS and forwards to Gunicorn. The web service must be reached
through Render's proxy when `TRUST_PROXY_HOPS=1`. No domain purchase is required.

## Verification after deployment

- `/health/live`: HTTP 200.
- `/api/health`: connected, expected observation count.
- Overview, Map, Time analysis, Vehicles: load and filter against real data.
- CSV and Excel: export the selected filters with matching row counts.
- Exceeding the configured export limit: HTTP 429 and `Retry-After`.
- HTTP redirects to HTTPS; no certificate warning.

## Free-tier limitations

Render web services sleep after 15 idle minutes; a cold start can take about a
minute. Free hours and bandwidth are shared at the workspace level, including
other projects. Avoid adding payment details for this zero-budget deployment;
without a payment method Render suspends services instead of billing overages.
Key Value counters reset on restart, which is acceptable for short rate windows.

Aiven Free currently includes 1 GB disk and may power down inactive services.
Free tiers suit a portfolio/demo; availability is not guaranteed. Keep the local
reviewed bundle and database backups for recovery.
